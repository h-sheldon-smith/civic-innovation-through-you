Commands on new computer to run the server:

python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
(or)
pip install Django
pip install python-dotenv
pip install freezegun

python manage.py runserver

Create Super User (SuperUser Account):
python manage.py createsuperuser

Promote Existing Account to Site Admin (City Administrator Account):
python manage.py promote_to_site_admin username
